# GreetFarm

A Cross-Platform Mobile Application for Direct Farm-to-Consumer Sales Using a Click & Collect Model.

Development Project - CIS6035
BSc (Hons) Software Engineering
Student: P.Kujilini (JF/BSCSD/18/28)

## Overview

GreetFarm connects small-scale farmers directly with local consumers through a
hyperlocal Click & Collect model, removing dependency on middlemen and reducing
food waste through a pre-booking Harvest Calendar.

## Technology Stack

- Frontend: Flutter (Dart)
- Backend: PHP REST API
- Database: MySQL
- AI Microservice: Python (Flask, scikit-learn)

## Key Features

- Hyperlocal product search with distance filtering
- QR-code-based collection confirmation
- AI-based demand prediction
- Real-time notifications
- Farmer sales analytics / customer spending analytics
- Admin panel for platform management

## Project Structure

- `lib/` — Flutter mobile application source code
- `greetfarm_api/` — PHP backend REST API
